# Object Detection App

Detects 80+ objects in images and videos using YOLOv8.

## Features
- Upload images to detect objects
- Webcam support for real-time detection
- Video file upload
- Confidence threshold adjustment
- Detects: person, car, dog, cat, chair, phone, etc.

## How to Run
1. Install dependencies:
   
   pip install -r requirements.txt
   
2. Run the app:
   
   streamlit run app.py
   
3. Open browser at: http://localhost:8501

## Technologies Used
- Python
- Streamlit
- YOLOv8
- OpenCV
- Ultralytics
